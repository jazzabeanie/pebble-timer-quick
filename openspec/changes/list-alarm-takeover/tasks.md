- 3.5: trim options, measured on aplite in a scratch copy (D6 order):

  | Trim | Saves | Result |
  |------|-------|--------|
  | None | 0 | overflow 1192 |
  | B: no mnemonic names on aplite (`"Timer N"`, drops `mnemonic.c` and its tables) | 1016 | overflow 176 |
  | C: no `TEST_LOG` / `test_log_state` output on aplite | 1408 | heap 216 |
  | D: `MAX_TIMERS` 5 to 3 on aplite | 112 | overflow 1080 |
  | B + D | 1128 | overflow 64 |
  | B + C | 2424 | heap 1232 |

  B + C + D brings aplite back to the baseline heap, which is still below the ~1.6 KB floor.
